# Collection Planner

Standalone Collection module: table, kanban, calendar, timeline (gantt), gallery, mind map and form views over one data model
(fields, records, relations, formulas, automations). State lives in the browser (localStorage). Entry: `src/App.tsx`,
UI: `src/renderers/CollectionSurface.tsx`, model/logic: `src/collections/`.

    pnpm install && pnpm dev      # run
    pnpm typecheck && pnpm test   # checks
